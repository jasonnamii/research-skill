# 사고도구 7층 — 내장 정의 (SSOT)

본 스킬이 §1~§5에서 쓰는 7층 사고도구의 **단일 진실원천(SSOT)**. 외부 스킬 의존 없음 (INV 9).
본문은 도구명을 그대로 박고 **여기 정의대로 적용**한다. 의역·변형·생략 = FAIL.

| 층 | 사고도구 | 정의 | 적용 위치 |
|---|---|---|---|
| L0 | **제1원리** | 유추·관행 차단 → 환원불가 자명명제까지 분해 → 의사결정으로 재조립 | §1-1 |
| L0 | **백본** | 결론먼저 → 역방향 전개 → 필수논거만 | §1-2 |
| L0 | **작업설계자** | 진입 시 작업 트리아지 + 모드 선택 (LIGHT/DEEP/TURBO/EXPAND) | 모드 |
| L0 | **트리아지** | 자원제약·긴급×중요 → 즉시/예약/위임/제거 | §3-3·§5 복귀 |
| L1 | **엄브렐러** | 소스를 5장르(공식·전문·커뮤니티·소셜·역설)로 MECE 배치 | §2-1 |
| L1 | **프리모르템** | 실패 확정 전제 → 역추적 → 치명원인 Top3 | §2-1·§2-2 |
| L2 | **홈즈** | ①관찰 ②이상징후 ③복수가설 ④증거대조 ⑤소거 | §2-1·§4 |
| L4 | **연역수렴** | 축간 교차(모순·강화·빈자리) 통합 수렴 | §2-3 |
| L4 | **오컴** | 가정 최소 채택 · 이진 판정(높음/낮음, 애매=낮음) | §2-3·§3-5 |
| L4 | **외과적** | 반전위험 점검 · 정밀 수정만 (과잉 개입 금지) | §2-3·§3-5 |
| L4 | **수정4** | L0~L4 회귀 수준 판정 (가설/프레임 흔들림 대응) | §2-4 |
| L5 | **아날로지** | 구조적 패턴 추출 + 타도메인 매핑 | §5 T2·T3 |
| L5 | **줌** | 미시↔거시 스케일 전환 · 개인/팀/조직/산업/사회 재조명 | §5 T3 |
| L6 | **맥가이버** | 제약 → 가용자원 재해석 · 비표준 용도 · 우회 경로 설계 | §3-2·§2-1 fallback |
| L6 | **틀밖** | 프레임 박제 → 거부 → 3대 킬샷(안 하는 답·대상/구조/방식 전환·아무도 안 묻는 질문) | §1-3·§5 T1 |
| L6 | **절대자** | 형 프레임 고정 + 빠진부분 전수탐색 + MECE | §1-3·§4 S2 |
| L7 | **스켈레톤** | 비본질 제거 · 뼈대만 잔존 | §3-4 |
| L7 | **제출청소** | 외부 노출 정제 · 작업 라벨 제거 (FINAL_RENDER_GATE 연동) | §3-4 |
| L7 | **타임스톤** | 복귀 서약 4항 선언 · 턴 타이머(최대 3턴) | §5-7 |
| 보조 | **넛지** | 선택자유 보존 · 디폴트 설계 · 의도방향 유도 | §4 자기고발 인센티브 (R1) |

**적용 원칙:**
- 도구는 해당 §에서 발동하고, 적용 결과를 산출물 본문에 노출한다(STEALTH 면제 — 도구명은 노출 가능).
- 깊은 정의가 필요하면 각 §의 적용 맥락(why/how/scope/blind/expand.md)에서 보강. 단, 정의 자체는 본 파일을 변형 없이 따른다 (drift 방지).
